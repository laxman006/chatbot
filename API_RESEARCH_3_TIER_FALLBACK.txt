We've implemented a comprehensive 3-tier fallback system to ensure the Cloud API Research

========================================
 TIER 3: LLM-POWERED GENERATION
========================================

✅ ADDED: OpenAI-powered documentation URL generation for unknown clouds

For clouds NOT in our static list, the LLM generates likely documentation URLs:
  - Uses common patterns (developer.*, docs.*, api.*, etc.)
  - Generates 3-5 most likely official URLs
  - Focuses on User/Group management, Auth, SCIM

Example: "Research APIs for ServiceNow"
  → LLM generates: developer.servicenow.com URLs

========================================
 HOW IT WORKS
========================================

When you search for a cloud's APIs:

1. TRY WEB SEARCH (ddgs library)
   ↓ If 0 results...
   
2. TRY STATIC FALLBACK (15+ pre-configured clouds)
   ↓ If not in list...
   
3. TRY LLM GENERATION (OpenAI generates likely URLs)
   ↓ If all fail...
   
4. SHOW ERROR: "No documentation found"
