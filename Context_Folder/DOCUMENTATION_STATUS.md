## 📝 Documentation Standards

Each documentation file should include:
1. **Overview** - What it does, why it exists
2. **Architecture** - High-level structure, diagrams
3. **Detailed Process** - Step-by-step workflows
4. **Configuration** - Settings, environment variables
5. **Key Functions** - Important functions with signatures
6. **Examples** - Code examples, usage examples
7. **Best Practices** - Recommendations, tips
8. **File Locations** - Where to find the code
