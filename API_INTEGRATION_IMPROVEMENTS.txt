====================================================================================================
 EXTRACTION STRATEGY (PRIORITY ORDER)
====================================================================================================

1. OpenAPI Spec File (if found)
   → Fetch directly from URL
   → Complete, structured data
   → Fastest and most accurate

2. OpenAPI YAML Blocks
   → Parse embedded YAML in code blocks
   → Extract paths, methods, operation IDs
   → Get base URL from servers field

3. Curl Examples
   → Extract from curl commands
   → Shows actual API calls
   → Very reliable

4. URL Patterns
   → Extract from page URL structure
   → Box-specific patterns
   → Good fallback

5. Structured HTML
   → Extract from HTML elements
   → Method + path from markup
   → Works for many docs

6. Regex Patterns
   → Fallback extraction
   → Box-specific patterns
   → Versioned API patterns

====================================================================================================
 WHAT YOU GET FOR INTEGRATION
====================================================================================================

For each cloud, you'll get:

1. BASE URL
   Example: https://api.box.com/2.0
   → Use this as the base for all API calls

2. ENDPOINTS
   Example:
   - GET    /users
   - POST   /users
   - GET    /users/{user_id}
   - PUT    /users/{user_id}
   - DELETE /users/{user_id}
   - GET    /groups
   - POST   /groups
   - GET    /groups/{group_id}/memberships
   - POST   /group_memberships
   - DELETE /group_memberships/{membership_id}

3. AUTHENTICATION
   Example:
   {
     "auth_type": "oauth2",
     "token_endpoint": "https://api.box.com/oauth2/token",
     "authorization_endpoint": "https://account.box.com/api/oauth2/authorize",
     "scopes": ["manage_enterprise", "manage_groups"],
     "admin_consent_required": true
   }

4. OPERATION MAPPING
   → Maps to CloudFuze operations (getUsers, createUser, etc.)
   → Provides operation IDs from OpenAPI
   → Includes descriptions
