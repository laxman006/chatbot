====================================================================================================
 QUICK START GUIDE - PRODUCTION-READY CLOUD API DISCOVERY
====================================================================================================

Follow these steps to activate the new, hallucination-free system:

====================================================================================================
 STEP 1: INSTALL DEPENDENCIES
====================================================================================================

Run these commands in your terminal:

```bash
pip install validators>=0.22.0
pip install playwright>=1.40.0
playwright install chromium
```

**What this does:**
- `validators` - URL validation (lightweight)
- `playwright` - JavaScript rendering library
- `playwright install chromium` - Downloads Chromium browser (~300MB, one-time)

**Time required:** 2-5 minutes (depending on internet speed)

====================================================================================================
 STEP 2: RESTART SERVER
====================================================================================================

In your server terminal:

```bash
Ctrl+C  # Stop current server
python server.py  # Start with new code
```

The new classification and JavaScript rendering will now be active!

====================================================================================================
 TROUBLESHOOTING
====================================================================================================

### ISSUE: "No module named 'validators'"

**Solution:**
```bash
pip install validators>=0.22.0
```

### ISSUE: "playwright: command not found"

**Solution:**
```bash
pip install playwright>=1.40.0
playwright install chromium
```

### ISSUE: "Canny still shows 75% coverage"

**Cause:** Using cached data

**Solution:**
```bash
python -c "from app.models.cloud_research import CloudResearchStore; store = CloudResearchStore(); store.collection.delete_one({'cloud_name': 'Canny'}); print('Cache cleared')"
```

Then restart server and try again.

### ISSUE: "Box still shows 0% coverage"

**Cause:** Using cached data or validators not installed

**Solution:**
```bash
pip install validators
python -c "from app.models.cloud_research import CloudResearchStore; store = CloudResearchStore(); store.collection.delete_one({'cloud_name': 'Box'}); print('Cache cleared')"
```

Then restart server and try again.
