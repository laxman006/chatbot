CLOUD API RESEARCH ASSISTANT - QUICK START
===========================================

OVERVIEW
--------
AI-powered assistant that automatically discovers and documents cloud provider APIs
for CloudFuze Manage integration. Researches official docs, extracts ALL endpoints,
and provides comprehensive blueprints with direct documentation links.

USAGE - CHAT INTERFACE
-----------------------
Simply ask the chatbot:

  "Research APIs for Slack"
  "What APIs does Okta have?"
  "Discover Asana user management APIs"

The bot automatically:
  1. Searches official documentation
  2. Extracts ALL API endpoints
  3. Maps to CloudFuze standard operations
  4. Returns markdown with documentation links
  5. Provides downloadable JSON blueprint

USAGE - API ENDPOINTS
----------------------
1. Research a cloud:
   POST /api/cloud-research/query
   {"cloud_name": "Slack", "force_refresh": false}

2. Get cached results:
   GET /api/cloud-research/Slack

3. List all researched clouds:
   GET /api/cloud-research/list

4. Download JSON blueprint:
   GET /api/cloud-research/Slack/download

CONFIGURATION
-------------
Add to .env:

  ENABLE_CLOUD_API_RESEARCH=true
  CLOUD_RESEARCH_WEB_SEARCH_API=duckduckgo
  CLOUD_RESEARCH_MAX_URLS_PER_CLOUD=10
  CLOUD_RESEARCH_CACHE_DAYS=30

WHAT YOU GET
------------
- Official documentation links for every operation
- Complete API endpoint catalog (not just core operations)

CLOUDFUZE STANDARD OPERATIONS
------------------------------
Core (Required):
  Users: getUsers, createUser, updateUser, deleteUser, suspendUser, restoreUser
  Groups: getGroups, createGroup, getGroupMembers, addUserToGroup, removeUserFromGroup
  Auth: getAccessToken, refreshToken

Extended (Optional):
  Applications, Licenses, Roles, Security, Audit Logs, Settings
