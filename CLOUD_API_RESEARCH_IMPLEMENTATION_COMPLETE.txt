HOW TO USE
================================================================================

STEP 1: ENABLE THE FEATURE
---------------------------
If you're a CloudFuze Manage team member or admin:

1. Open the chat interface
2. Look in the sidebar - you'll see a new button:
   
   🔒 API Research: OFF  (gray button)
   
3. Click the button
4. It turns green:
   
   🔬 API Research: ON ✓  (green button)
   
5. Now you're ready to research cloud APIs!

STEP 2: RESEARCH A CLOUD
-------------------------
Just ask in chat:

   "Research APIs for Slack"
   "What APIs does Okta have?"
   "Discover Asana user management APIs"

STEP 3: GET RESULTS
-------------------
The bot will automatically:
- Search official documentation
- Extract ALL API endpoints
- Map to CloudFuze standard operations
- Return comprehensive markdown with:
  ✓ Official documentation links
  ✓ All available endpoints
  ✓ SCIM support detection
  ✓ SDK recommendations
  ✓ Coverage analysis
  ✓ Downloadable JSON blueprint

STEP 4: DISABLE WHEN DONE
--------------------------
Click the toggle again to disable:

   🔒 API Research: OFF  (gray button)

Now research queries will be treated as normal chat questions.

CONFIGURATION
================================================================================

Add to .env (if not already present):

# Global feature flag
ENABLE_CLOUD_API_RESEARCH=true

# Web search (default: duckduckgo - no API key needed)
CLOUD_RESEARCH_WEB_SEARCH_API=duckduckgo
CLOUD_RESEARCH_SEARCH_API_KEY=

# Scraping settings
CLOUD_RESEARCH_MAX_URLS_PER_CLOUD=10
CLOUD_RESEARCH_SCRAPING_DELAY=2

# Cache settings
CLOUD_RESEARCH_CACHE_DAYS=30
CLOUD_RESEARCH_VERIFY_URLS=true
CLOUD_RESEARCH_MIN_CONFIDENCE=0.7

ISSUE: "Failed to toggle API research"
FIX: Check MongoDB connection. Verify user_profiles collection exists.

ISSUE: Research takes too long
FIX: Normal. First research takes 30-60s. Cached results return instantly.

FIX: Cloud may have limited public documentation. Check confidence score.
