 1. UNIVERSAL DOMAIN DETECTION
====================================================================================================

NEW FILE: app/domain_detector.py

FEATURES:
- Automatically detects official domain for ANY cloud
- No hardcoded lists required!
- Tries common TLD patterns: .com, .io, .dev, .ai, .co
- Verifies domain accessibility before returning

EXAMPLE:
```python
cloud_name = "Canny"
# Automatically detects: canny.io ✓

cloud_name = "Notion"
# Automatically detects: notion.so ✓

cloud_name = "Linear"
# Automatically detects: linear.app ✓
```

HOW IT WORKS:
1. Cleans cloud name (remove spaces, special chars)
2. Tries each TLD pattern in order of likelihood
3. Verifies each domain exists (HEAD request)
4. Returns first valid domain found

FINDS DOCUMENTATION URLS:
Once domain is detected, automatically checks:
- https://developers.{domain}
- https://developer.{domain}
- https://docs.{domain}/api
- https://{domain}/docs/api
- https://api.{domain}/docs
... and 5 more patterns

 2. SMART URL FILTERING (STRICT VALIDATION)
====================================================================================================

UPDATED: app/web_tools.py - filter_official_sources()

BEFORE (BROKEN):
- Accepted ANY URL with "api" or "developer" keywords
- Result: Accepted restfulapi.net, random GitHub repos, OpenAI docs for Canny search

AFTER (FIXED):
- Uses UniversalDomainDetector for validation
- Requires cloud name OR official domain in URL
- Rejects generic tutorial sites, competitors, random repos
- Scores each URL (0-100) based on relevance
- Returns URLs sorted by score (best first)

REJECTION RULES:
✗ wikipedia.org
✗ stackoverflow.com
✗ reddit.com
✗ tutorialspoint.com
✗ restfulapi.net
✗ github.com/awesome (generic collections)
✗ github.com/topics
✗ Competitor domains (unless exact match)

SCORING SYSTEM:
+50 points: Official domain match (e.g., canny.io for "Canny")
+40 points: Likely official domain (.com/.io match)
+20 points: Developer subdomain (developers.X, developer.X)
+15 points: API subdomain (api.X)
+10 points: Documentation path (/docs/, /api/, /reference/)
+5 points: Auth-related (/oauth, /authentication)
-20 points: Not HTTPS

THRESHOLD: 30 points minimum to be accepted

EXAMPLE (Canny):
BEFORE:
  ✗ https://restfulapi.net/ (generic tutorial) - Accepted
  ✗ https://platform.openai.com/docs (wrong company) - Accepted
  
AFTER:
  ✗ https://restfulapi.net/ - Rejected (generic site)
  ✗ https://platform.openai.com/docs - Rejected (no "canny" in URL)
  ✓ https://developers.canny.io/api-reference - Accepted (score: 80)
  ✓ https://canny.io/api/authentication - Accepted (score: 75)

 5. MONGODB VERSION ERROR FIXED
====================================================================================================

UPDATED: app/models/cloud_research.py

ERROR:
```
ERROR: Updating the path '_version' would create a conflict at '_version'
```

CAUSE:
- Used both $inc and $setOnInsert on same field (_version)
- MongoDB doesn't allow this

FIX:
- Check if document exists first
- If exists: use $inc to increment version
- If new: insert with _version = 1
- No more conflicts!
