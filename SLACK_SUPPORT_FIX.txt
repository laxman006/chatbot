====================================================================================================
 SLACK'S API PATTERN (Different from Standard REST)
====================================================================================================

STANDARD REST APIs (Okta, Google, Azure):
  GET    /api/v1/users
  POST   /api/v1/users
  DELETE /api/v1/users/{id}

SLACK'S METHOD-BASED APIs:
  POST /users.list
  POST /users.info
  POST /admin.users.invite
  POST /admin.users.remove
  POST /usergroups.list
  POST /usergroups.users.list

KEY DIFFERENCES:
1. Use POST for reads (not GET)
2. Use dot-notation (method.action)
3. No /api/ prefix
4. No version numbers in path
